# KB-10 engineering acceptance

KB-10 adds immutable source-selected exact and Chinese lexical candidate retrieval. It preserves standard prefix/year, separate method and judgment standards, source review state, original match spans, unknown applicability, and explicit degraded/failed results. Migration 013 appends three tables and GIN candidate indexes; existing migrations and remote classifier content remain unchanged.

The local PostgreSQL 18.6 run passed 716 tests with no failures or skips. Source-selected replay retained 8,272 candidate records, tested 36 scenarios, repeated the same generation with zero increment, and verified prior domain rows and source artifacts were unchanged. Ten actual CLI paths produced valid UTF-8 JSON and did not mutate the 49 domain tables. Offline browser checks cover saved queries, ranking/source text, fault labels, narrow layout, local source hashes, and exact JSON downloads. A subsequent title/field-label adjustment was verified separately after the full suite.

Six explicitly attributed engineering source queries contain eight selected relevant record labels. Raw literal lookup found three; normalized phrase and indexed Chinese lookup found eight. Each strategy also returned five unjudged related-body hits, retained separately with label coverage and precision bounds. A five-record synthetic closed corpus provides five separate negative/format queries. These figures are not expert food relevance accuracy or a complete golden set. Warm local query means were approximately 264/324/321 milliseconds for raw/normalized/indexed modes; integrity verification is included, and the shared PostgreSQL instance also ran isolated regression work during this replay. No concurrency SLA is claimed.

An early synthetic symbol assertion omitted two legitimate source channels; the corrected assertion checks all three roles and original spans. The first actual node-ID assertion omitted five associated inspection rows; exact classification and associated-row checks are now separate, with the original failed attempt retained locally. These corrections did not remove legitimate records or alter the frozen business index.

Body full text covers one accepted manual standard only. Other 2,018 registered versions explicitly retain body-not-indexed gaps. Unreviewed aliases do not expand queries. Real knowledge remains pending review and non-executable; hits do not approve applicability, historical date policies, semantic classifications, or complete required tests. Vector providers, expert gold labels, complete evidence expansion and rule execution remain outside KB-10.

Original standards, manual body text, business datasets, result artifacts, local configuration, backups, passwords and keys are excluded from this repository. Local replay scripts require those separately retained inputs and explicit baselines. Tests use synthetic sources in dedicated test schemas; private-input tests skip explicitly when excluded fixtures are unavailable.
